# VideoAutomation 利用者マニュアル

ローカル AI と対話しながら、台本 → 音声 → 字幕 → 編集 → 書き出し → 品質検査まで行う動画編集アプリです。
AI が提案した変更は、利用者が承認するまで反映されません。

- 運用・トラブル対応: [OPERATIONS.md](OPERATIONS.md)
- 仕様書: [VIDEO_AUTOMATION_SPEC.md](VIDEO_AUTOMATION_SPEC.md)

---

## 1. 必要なソフト

| ソフト | 用途 | 必須 | 入手・設定 |
|---|---|---|---|
| Windows 10/11（64bit） | 動作環境 | 必須 | — |
| FFmpeg | 動画の編集・書き出し・品質検査 | **必須** | `winget install Gyan.FFmpeg` などで入れ、PATH を通す |
| Ollama または LM Studio | 台本の生成・AI アシスタント | AI 機能に必要 | Ollama は 127.0.0.1:11434、LM Studio は 127.0.0.1:1234 を自動検出 |
| VOICEVOX Nemo / VOICEVOX Engine | 読み上げ音声 | 音声に必要 | Nemo は 127.0.0.1:50121、Engine は 127.0.0.1:50021 |
| Blender（4.x / 5.x） | 文字アニメーション・図表 | 任意 | 既定のインストール先と Steam 版を自動検出 |
| ACE-Step 1.5 | BGM 生成 | 任意 | `VA_ACESTEP_PATH` にフォルダを指定 |
| NVIDIA GPU | 書き出しの高速化（NVENC） | 任意 | 使える場合は自動で使う |

VRAM 8GB の場合、LLM は 1 つずつ読み込みます（BGM 生成の前には LLM を外します）。

## 2. インストール

1. 配布 zip（`VideoAutomation-<版>-windows.zip`）を任意のフォルダに展開します。
2. 展開したフォルダの `install.bat` をダブルクリックします。
   - 既定のインストール先は `%LOCALAPPDATA%\VideoAutomation` です。
   - Python 3.12 と必要なパッケージは、パッケージ管理ツール uv が自動で用意します。uv が入っていない場合は、
     `install.bat -InstallUv` で公式インストーラーから入れられます（インターネット接続が必要）。
   - デスクトップとスタートメニューに「VideoAutomation」のショートカットを作ります
     （作らない場合は `install.bat -NoShortcut`）。
3. 最後に動作環境の確認結果が表示され、`install_log.txt` にも保存されます。

更新するときは、新しい zip で同じ手順を行います。`data` フォルダ（プロジェクト・素材・書き出し）と
`.env`（設定）は残ります。

アンインストールは、インストール先の `uninstall.bat` を実行します。データも消す場合は
`uninstall.bat -RemoveData` を使います。

## 3. 起動と画面

ショートカット、またはインストール先で `.venv\Scripts\video-automation.exe` を実行します。
内部で API（127.0.0.1:8765）を起動し、次のタブを表示します。

| タブ | できること |
|---|---|
| プロジェクト | API の接続確認・プロジェクト一覧 |
| LLM設定 | モデルの検出・推論テスト・タスク別のモデル割り当て |
| 音声 | 話者の選択・試聴・読み/アクセント/抑揚の調整・辞書 |
| 台本作成（AI） | キャラクターと設定を決めて AI と台本を作る |
| 台本・字幕 | 台本の音声生成・字幕生成と同期・ASS/SRT 出力 |
| 素材・BGM | 素材検索（Pexels / Pixabay / Freesound / Openverse / Wikimedia）・BGM 生成 |
| 編集・書き出し | タイムライン・演出・テロップ・プレビュー・書き出し・承認 |
| AIアシスタント | 会話で編集を指示し、提案を差分で確認して承認・却下・取り消し |
| 品質検査 | 音声・字幕・映像・ライセンスの検査結果 |

## 4. 基本の流れ

### 4.1 プロジェクトを作る
解像度（例: 1920×1080 / 1080×1920）とフレームレート（例: 30fps）を決めて作成します。

### 4.2 台本を作る（台本作成（AI）タブ）
1. **モードを選びます。**
   - 全自動: AI が全員分のセリフを作ります。
   - 片側入力: 「ユーザー担当」にしたキャラクターのセリフをあなたが書き、相手役を AI が作ります。
   - 手動: AI を使いません。
2. **キャラクター**（名前・役割・性格・口調・話者 ID）と**設定**（テーマ・目的・視聴者・目標尺・
   必須キーワード・禁止事項・参考資料）を入力し、「新規作成」を押します。
3. 片側入力では、自分のセリフを 1 行 1 発話で入力して「セリフを追加」を押します。
4. 「AIで生成」を押します。ローカル LLM では数十秒〜数分かかります。
5. セリフ一覧の色で生成元が分かります（青=ユーザー入力、白=AI、黄=手修正）。
   - **固定**したセリフ・ユーザー入力・手修正したセリフは、再生成しても AI が変えません。
   - 1 発話だけ直したいときは「言い換え候補（3案）」から選んで「候補を採用」します。
6. 「検証」で、話者・禁止語・必須語・推定尺などを確認します。「検証（LLMで整合性も）」では、
   会話のつながりやキャラクターの口調も AI が確認します。
7. 変更は版として残り、「最新版との差分」「この版に戻す」で比較・復元できます。

### 4.3 音声と字幕（台本・字幕タブ）
「台本」欄で台本を選び（台本作成（AI）で作ったものも選べます）、「2. 音声を生成」→「3. 字幕を生成・同期」を
行います。テキストから新しく作る場合は、下の欄に入力して「1. 台本を作成」を押します。
台本作成（AI）で設定した話者 ID・話速などが使われます。
字幕は音声の実際の時刻に合わせ、フレーム単位に揃えます。ASS / SRT で書き出せます。

### 4.4 編集（編集・書き出しタブ / AIアシスタントタブ）
- 「台本から配置」で音声を並べ、素材を置き、演出（ズーム・パン・登場/退場・切替）やテロップを付けます。
- AI アシスタントには「冒頭3秒に画像を置いてフェードインして」のように指示します。AI の提案は
  **承認待ち**に入り、差分（何がどう変わるか）を見て承認・却下します。
- 「編集履歴」から指定の時点まで戻せます。別のモデルで同じ指示をやり直すこともできます。

### 4.5 書き出し
出力形式（フルHD 横/縦・4K 横/縦）を選んで書き出します。字幕の焼き込みと、外部字幕（SRT/ASS）の出力を
選べます。音量はネット配信向け（-14 LUFS）に揃えます。

### 4.6 品質検査（品質検査タブ）
「品質検査を実行」で、最新の書き出しを中心に次の項目を検査します。

| 項目 | 主な検査内容 |
|---|---|
| タイムライン | 空・重なり・素材ファイルの欠落 |
| 音声品質 | 音割れ（ピーク）・小さすぎる音量・セリフ間の音量差・前後/途中の長い無音・読み上げ速度 |
| 字幕同期 | 未同期・重なり・音声区間からのはみ出し・表示時間・読む速さ・行数/1 行の文字数 |
| 映像品質 | 解像度・フレームレート・長さ・音声の有無・ラウドネス・トゥルーピーク・黒画面・静止 |
| ライセンス | 未確認・商用不可・改変禁止素材の加工・継承条件・必要なクレジット |

結果は「要修正（赤）」「要確認（黄）」「参考」に分かれます。要修正がなくなるまで直してから公開してください。
動画内の位置（分:秒）が出る項目は、プレビューで該当箇所を確認できます。

## 5. 素材とライセンス

- 素材は取得元・取得日時・ライセンス条件を保存し、「クレジット」に概要欄用の表記をまとめます。
- ライセンスが不明・商用不可などの素材は、利用者が明示的に確認するまで使えません。
  AI が取り込みを提案した場合は承認待ちになります。
- 設定（AIアシスタント → 承認ポリシー）で、「AI による素材ダウンロードを承認なしにする」
  「ライセンス不明素材を使わない」を選べます。タイムライン変更・書き出し・台本修正案の承認は外せません。
- Pexels / Pixabay / Freesound は API キーが必要です（素材・BGM タブで登録。Windows の DPAPI で暗号化して保存）。

## 6. AI との連携（MCP）

Claude Desktop などの MCP クライアントから操作できます。

| サーバー | 起動コマンド | 主なツール |
|---|---|---|
| mcp_core | `video-automation-mcp` | モデル検出・選択、プロジェクト作成、状態取得、編集計画（plan_edit） |
| mcp_media | `video-automation-mcp-media` | 音声・字幕・素材検索/取得・BGM |
| mcp_render | `video-automation-mcp-render` | タイムライン・プレビュー・検証・書き出し・品質検査 |
| mcp_visual | `video-automation-mcp-visual` | シーン・アニメーション・切替・図表 |
| mcp_script | `video-automation-mcp-script` | 台本作成・生成・再生成・固定・検証・版 |

MCP から行った変更（編集・書き出し・素材の取り込み・台本の生成）は、すべてアプリでの承認後に反映されます。

## 7. 困ったとき

まずインストール先で次を実行し、足りないものを確認してください。

```
.venv\Scripts\video-automation.exe --doctor
```

よくある症状と対処は [OPERATIONS.md](OPERATIONS.md) にまとめています。
