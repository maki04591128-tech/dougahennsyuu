# 動画自動化ブリッジ（Blender アドオン）

Blender の動画編集（Video Sequencer）から、同じ PC で動いている動画自動化アプリを操作する拡張機能。

## 入れ方

1. 拡張機能の zip を作る（または配布された `video_automation_bridge-0.1.0.zip` を使う）

   ```
   blender --command extension build --source-dir tools/blender_addon/video_automation_bridge --output-dir <出力先>
   ```

2. Blender の「編集 → プリファレンス → 拡張機能（Get Extensions）」右上の ∨ →「ディスクからインストール」で zip を選ぶ
3. アプリを起動しておく（画面ありでも `video-automation --headless` でもよい。既定 http://127.0.0.1:8765）

対応: Blender 4.2 以降（5.3.0 で確認）。

## 使い方（Video Sequencer のサイドバー［N キー］→「動画自動化」タブ）

| 欄 | できること |
|---|---|
| 1. 接続 | アプリにつなぎ、プロジェクト・台本・用途の一覧を読み込む |
| 2. 作るもの | 作りたいものを文章で書いて用途（字幕動画・解説・MV など 22 種）を判定し、その用途のデザインの型を設定する。別用途の演出は使われない |
| 3. 作る手順 | 音声 → 字幕 → 演出 → デザイン検査 → 書き出し を 1 つずつ、または「すべて続けて」。待ち時間の長い処理は裏で動き、Blender は止まらない |
| 4. 読み込み | 書き出した動画（音声つき）を空いているチャンネルに置く。空のシーンなら解像度とフレームレートを動画に合わせる |

台本やキャラクター・声の設定はアプリの画面で行う。

## 安全のための決まり

- 接続先は同じ PC（`http://127.0.0.1`・`localhost`・`::1`）だけ。ほかのホストは拒否する。プロキシも通さない
- API キーなどの秘密は扱わない（アプリ側で暗号化して保存・使用する）
- デザインの検査で止まった書き出しを、このアドオンから強制することはできない（アプリで判断する）

## テスト

通信部分（`client.py`）は bpy に依存しないので、`tests/integration/test_blender_addon_client.py` で
実際のアプリ（uvicorn）につないで確かめている。
