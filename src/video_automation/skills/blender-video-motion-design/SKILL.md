# Blender で作る動画の演出（解説動画・MV/PV）

「何を見せたいか」から Blender の技法を選び、字幕や音声と合う素材を作るための指針。
具体的なコードは `blender-5-scripting` スキル（Blender 5.x の API とレシピ）を使う。両方を読み込んでから作業する。
**MV/PV は 3D を作らなくても、Blender の動画編集機能（VSE）でカット・切り替え・色・文字・光を組める。** その場合は `blender-vse-mv-editing` スキルを読む（拍の検出、拍でのカット、調整レイヤー、コンポジタモディファイア、テキストストリップ、書き出し）。

**写真を並べるだけで終わらせない。** 3D・アイソメトリック、モーショングラフィックス、インフォグラフィック、タイポグラフィ、ピクトグラム、モンタージュの使い分けと作り方は `advanced-motion-techniques`。配置と重なり防止は `layout-no-overlap`。

## 進め方
1. 台本（または歌詞）を場面に分け、場面ごとに**見せたいもの**を 1 つ決める（概念・比較・手順・数値・結論）
2. 下の表で技法を選ぶ。1 場面に動きの主役は 1 つ
3. 字幕の位置・発話の長さ（秒）から、各素材の長さと配置を決める
4. 低解像度（960×540・16 サンプル）で要所のフレームを描いて**画像を見て**確認 → 直す → 本番解像度で書き出す
5. 書き出した素材を動画編集側（タイムライン）に並べ、字幕・音声と合わせて確認する

## 何を見せるか → 技法

| 見せたいもの | 技法（Blender） | 書き出しの重さ |
|---|---|---|
| 題名・章の始まり | 立体文字（押し出し＋面取り）、弾む登場（BACK / EASE_OUT）、発光＋グロー、被写界深度 | 中 |
| 物・構造（分子、部品、地形） | 球と棒の模型・プリミティブの組み合わせ、ゆっくり回す（1 周 4〜8 秒、LINEAR） | 小〜中 |
| 数値の比較 | 3D 棒グラフ（棒を順に伸ばす）、数値を文字で添える、比べたい項目だけ色を変える | 小 |
| 変化・手順・流れ | 線が伸びる（カーブの bevel_factor_end）、矢印、カメラで次の要素へ移る | 小 |
| 重要な語・数値 | 透明背景で描いた立体文字を重ねる、1 文字ずつ出す（ジオメトリノード） | 小 |
| 雰囲気・背景・間 | ジオメトリノードで格子・粒子をノイズで動かす（ループ）、ゆっくりしたカメラ移動 | 小 |
| 手書き・注釈・ゆるい雰囲気 | Grease Pencil（線の描画）、トゥーン調＋輪郭線 | 中〜大（輪郭線は重い） |
| 臨場感 | カメラの揺れ（ノイズ修飾子）、モーションブラー（速い動きのみ） | 中 |

MV/PV では
- 歌詞は「1 文字ずつ出す」「語ごとに弾む」を拍に合わせる（拍の時刻は音声側で解析し、フレームに直してキーを打つ）
- 背景はループする動き（ノイズを時間で動かす、`frame_end` 周期で回転）にすると長さを合わせやすい
- 切り替えは拍・小節の頭に置く

## 構図（字幕と重ねない）
- 16:9 の場合、字幕の帯（下 25〜30%）には何も置かない。**主役は画面の上 7 割の中央**、補助のテロップは左上
- 9:16 の場合は字幕が下 20% 程度、主役は中央より少し上。横長の文字は小さくなるので改行する
- 文字はカメラを作ってから画面幅の 70〜80% に合わせる（`fit_width`）。はみ出しが一番多い失敗
- 端から 5% は余白（スマホでの表示・切り取りに備える）
- 立体物は少し上から見下ろす（カメラの高さを被写体より上に、注視点を被写体の中心に）

## 文字
- 日本語は必ずフォントを読み込む（Meiryo Bold、Yu Gothic Bold、Noto Sans CJK Bold など。`.ttc` も使える）
- 押し出しは文字の大きさの 5〜15%、面取りは 1〜2%。押し出しが大きいと読みにくい
- 明るい文字は暗い背景に。金属の文字はキーライトと輪郭光が無いと黒く沈む
- 読める時間を確保する（字幕の目安は日本語で 1 秒に 4 文字前後）

## 色
- 図・文字・ロゴなど**決めた色をそのまま出す**: View Transform を `Standard`
- 写実的な物体・光の表現: `AgX`（5.x の既定）。色が淡く見えるのは仕様。鮮やかにしたいときは露出・彩度を調整する
- 色数は少なく: 背景（暗い紺など）＋主役の色＋強調色 1 つ。話者や項目ごとの色は動画全体でそろえる
- 発光（Emission）とグローは強調したい所だけに使う。全部光らせると何も目立たない

## 動き・タイミング
- 登場 0.3〜0.6 秒、退場はそれより短く。登場は EASE_OUT（EXPO / BACK / CUBIC）、退場は EASE_IN
- 複数の要素は 3f（0.1 秒）ずつずらす（棒グラフの棒）。カードの新しい項目は下 16px から不透明度 0→1、11f の easeOutCubic で足す（統合版 D1・D3）
- カメラ移動はゆっくり（SINE / EASE_IN_OUT）、同時に被写体も大きく動かさない
- 発話の切れ目（字幕が変わる所）に動きの区切りを合わせる。素材の長さは発話の長さから決める
- 動かない時間も必要。説明中はわずかな動き（ゆっくり回る、少し寄る）にとどめる

## 光
- **図・文字・アイコンには光を当てない**（Emission の色で塗り、View Transform は Standard、ブルーム・ビネットなし）。光を当てるのは 3D の立体物だけ
- 3 点照明（キー・フィル・輪郭光）を基本に。輪郭光で暗い背景から形を分離する
- 背景（ワールド）は平らな単色にしない。グラデーション＋ゆっくり動く図形・模様、または床と被写界深度で奥行きを付ける

## 書き出し時間の見積もりと節約
- 目安（RTX 5050・EEVEE）: 1080p・64 サンプル・立体文字＋被写界深度＋グローで約 0.5 秒／フレーム → 1 分あたり約 15 分
- 節約: 場面ごとに分けて描く、動かない区間は 1 枚だけ描いて伸ばす、透明素材と背景を分ける、確認は 960×540・16 サンプル、輪郭線（Freestyle）は要所だけ
- 長い書き出しは PNG 連番にして、止まっても続きから描けるようにする
- 同じ設定の素材は使い回す（題名のテンプレート、背景のループ）

## 動画編集（タイムライン）との組み合わせ
- 解説動画: Blender で描くのは「場面の映像」と「重ねる素材（透明背景）」。字幕・音声・カットの並びは動画編集側で行う
- MV/PV: 編集そのものを Blender の VSE で行える（`blender-vse-mv-editing`）。3D はシーンストリップか PNG 連番として VSE に置く
- MV/PV の編集の基本: 切り替えは 2 拍か 4 拍ごと（サビは細かく）、切り替えの種類は 2〜3 種に絞る、全体の色は調整レイヤーで 1 つにそろえる、フラッシュは 1 曲に数回、歌詞は拍の頭で出す
- フレームレート・解像度はプロジェクトと同じにする（30fps・1920×1080 など）
- 素材の長さ＝その場面の発話の長さ＋前後の余裕（0.2〜0.5 秒）。足りないと最後のフレームで止まる
- 透明素材は PNG（RGBA）連番、または透過付きの MOV にして重ねる

## 画面録画の解説動画（既定は強化版の演出）
- 操作説明・使い方・解説で画面録画を見せるときは、`screen-tutorial-direction` の演出を最初から全部入れる（外すのは依頼で明示されたときだけ）
- 操作箇所へのズーム: クリックの 0.5 秒前〜2.5 秒後はその位置、画面が変わった範囲があればそこ、何もしていない間は 1.0 倍に引く。止まったカーソルを追わない
- カーソルの光＋クリックの波紋（0.5 秒）＋クリック音。章の頭に章カード（1.7 秒）・見出しの帯・進み具合の棒・切り替え音
- BGM は声の区間で声のピークより 20dB 下、1 秒以上の台詞の間は 7dB 上げる（上げ下げは 0.4 秒。100Hz 以下を切り、2kHz を −3dB）、効果音は 2 種まで。立ち絵は同じ作者のフリー素材で、中央を向かせ、台詞に合わせて表情とポーズを変え、予備動作→動作→行き過ぎ→戻りで人間らしく動かす（話している方を明るく・口を動かす）
- ズームはばねで追い続けず、ショット（寄る先）を決めて 0.45〜0.8 秒の加速→減速で移り、着いたら止める
- 字幕は名前を出さず、話者ごとの書体・色で区別する
- 立ち絵は左右の余白に置き、録画の枠と字幕に重ねない（録画の枠を左右 280〜300px 狭める）

## 品質チェック（書き出し後に画像で確認）
- [ ] 文字・物が画面からはみ出していない、字幕の帯と重なっていない
- [ ] スマホ（縮小表示）でも文字が読める
- [ ] 主役が 1 つに絞られている。強調色・発光を使いすぎていない
- [ ] 動きの緩急がある（等速の登場が無い）、同時に動く要素が多すぎない
- [ ] 明るさ・色が場面間でそろっている、光の向きが一定
- [ ] ちらつき（サンプル不足）・黒つぶれ・白飛びが無い
- [ ] 数値・単位・ラベルが台本と一致している
- [ ] 写真を置いて寄るだけの場面が続いていない（技法を 3 種類以上使っている）
- [ ] 背景が単色の場面が無い。図・文字に不要な光（ブルーム・ビネット・陰り）が無い
- [ ] 立ち絵・テロップ・字幕が重なっていない。立ち絵が切れていない
