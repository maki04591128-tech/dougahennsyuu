# 合成音声のテンポとイントネーション

合成音声が「機械っぽい」と感じられる原因は、ほとんどが次の 3 つ。
**セリフ間の間が一律**（会話のリズムが無い）、**読み・アクセントの誤り**（固有名詞・数字・英字）、**抑揚が平ら**（強調したい語が立たない）。

## 1. テンポ（間の長さ）

セリフの間は一律にしない。直前の文の終わり方と、話し手が変わるかで決める。

| 場面 | 間（秒） |
|---|---|
| 同じ人が続けて話す（文の途中で区切っただけ） | 0.10〜0.15 |
| 同じ人が次の文へ | 0.20〜0.30 |
| 話し手が交代（相づち・即答） | 0.10〜0.20 |
| 話し手が交代（質問への答え） | 0.25〜0.40 |
| 驚き・オチの前（ため） | 0.50〜0.80 |
| 章・話題の切り替え | 0.70〜1.00（効果音や章カードを置く） |

- 「！」「？」で終わるセリフに相手がすぐ反応するなら短く、考えてから答えるなら長くする
- アプリの字幕の同期（gap_mode=auto、既定）はこの表のとおりに間を入れる（「実は」「なんと」で始まる文の前はため、シーンが変わる所は話題の切り替え）。全体を速く・遅くしたいときは gap_scale（0.8 で 2 割短く）を変える。一律にしたいときだけ gap_mode=fixed
- 台本の読み上げでは、セリフの前後の無音を 0.05 秒にしている（voice_edge_silence）。間はタイムライン上で作る
- 解説動画の話速は 1.0〜1.15 倍（1 秒に 6〜8 文字）。ショート・実況は 1.15〜1.3 倍。子ども向け・講義は 0.95〜1.05 倍
- 読点「、」の間（pauseLength）は 0.12〜0.2 秒。読点が 1 文に 3 つ以上あると間延びするので、台本側で減らす
- 文頭の無音（prePhonemeLength）は 0.05〜0.1 秒、文末（postPhonemeLength）は 0.05〜0.1 秒。セリフ間の間は、文末の無音ではなくタイムライン上の間で作る

## 2. 読み違い・アクセント違いを直す

声を作る前に、次を必ず確かめる。

- 固有名詞（地名・人名・作品名）・専門用語・英字・略語・数字＋単位（3776m、2013年、1707年）
- 読みを確かめる語は、アプリの「読みのルール」（台本の文字を読みに置き換える）か、エンジンの辞書（読み＋アクセント型）に登録する
  - 例: 「VideoAutomation」→「ビデオオートメーション」、「3776m」→「さんぜんななひゃくななじゅうろくメートル」、「浅間大社」→「せんげんたいしゃ」
- 数字は桁で読みが変わるので、単位まで含めて登録する。年号は「にせんじゅうさんねん」のように読みを書く
- アクセントがおかしい語は、辞書で**アクセント型（何拍目で下がるか）**を指定する。例: 「富士山（ふじさん）」は 1 拍目が高い頭高型
- 同じ語が複数の読みを持つ（「上手」「今日」「行った」）ときは、文脈で読みを決めて登録する

## 3. 抑揚（平ら・不自然を直す）

- 抑揚（intonationScale）は解説 1.0〜1.15、元気なキャラクター・ショート 1.15〜1.3。1.4 を超えると歌うように聞こえる
- 音の高さ（pitchScale）は原則 0（変えない）。キャラクターの声質が崩れる
- 疑問文は文末が上がっているか確かめる（「？」が付いていても、文末が名詞だと上がらないことがある。上がらなければ文末を「〜なの？」「〜ですか？」にする）
- 強調したい語（数字・結論）は、その語の直前に読点を入れて間を作ると立つ。抑揚を上げるより自然
- 1 文が長いと後半の抑揚が平らになる。40 文字を超える文は分ける

## 4. 作業の順番

1. 台本ができたら、読みの点検（AI の読みチェック）で固有名詞・数字・英字を洗い出す
2. 読みのルールと辞書に登録し、声を作る前に反映する
3. 声を作り、セリフ間の間を上の表で決めてタイムラインに並べる
4. 聞いて、読み違い・不自然な抑揚・詰まりすぎ／間延びのあるセリフだけを作り直す（台本の文を短くする・読点を足す・辞書に登録する）

## 5. 点検

- [ ] 固有名詞・数字・英字の読みがすべて正しい
- [ ] セリフ間の間が一律でない（話し手の交代・話題の切り替えで長さが違う）
- [ ] 話速がジャンルの範囲に入っている（1 秒に 6〜8 文字が目安）
- [ ] 疑問文の文末が上がっている
- [ ] 40 文字を超える文が無い
