# キャラクターの性格と口調を守った台本

キャラクターの台本で一番目立つ失敗は、**一人称や語尾の取り違え**（四国めたんが「僕」と言う）と、**設定に無い乱暴さ**（ずんだもんが「お前ら…思ってんのか？」と言う）。
口調は語尾だけで決まらない。一人称・相手の呼び方・語尾・性格・役割の 5 つをそろえて初めて「その人らしく」なる。

## 1. 書く前に、キャラクターごとに 5 項目を確かめる

| 項目 | 例（ずんだもん） | 例（四国めたん） |
|---|---|---|
| 一人称 | 僕（自分の名前「ずんだもん」も使う） | わたくし |
| 相手の呼び方 | オマエ・みんな | アンタ・貴女 |
| 語尾 | 〜のだ・〜なのだ | 決まった語尾なし。基本はタメ口 |
| 性格 | ずんだ餅の精。やや不幸属性で、ないがしろにされることもある | 誰にでも遠慮しない。若干ツンデレ。趣味は中二病妄想、常に金欠 |
| 掛け合いでの役割 | 説明役・ボケ役になりやすい | 聞き役・ツッコミ役になりやすい |

- 一人称・呼び方・語尾は**アプリの「声の口調」の設定が正**。この表と違えば設定に従う
- 設定に無い性格（乱暴・下品・過度な敬語）を足さない。視聴者を「お前ら」と呼ばない（相手の呼び方の設定に従う。視聴者全体は「みんな」など）
- 性格の特徴（めたんの金欠・中二病、ずんだもんの不幸属性）は**1 本の動画に 1〜2 回**だけ出す。毎回入れるとくどい。話の筋と関係ない所に入れない

## 2. 書き方

- 1 つのセリフは 1 つの役割（説明・質問・相づち・ツッコミ・まとめ）。1 セリフ 60 文字以内を目安に、長ければ分ける
- 説明役は結論を先に言い、聞き役が質問や驚きで次の話題を引き出す（説明 → 反応 → 補足 の 3 拍）
- 語尾「〜のだ」は文末ごとに付けなくてよい。2 文続くなら片方を「〜なのだ」、もう片方を言い切りにして単調さを避ける。ただし語尾の無いキャラクターに語尾を付けない
- 聞き役のセリフを「へえ」「なるほど」だけにしない。驚き・疑問・自分の経験・軽い反論のどれかを入れる
- 相手の名前を呼ぶときは、設定された呼び方か名前を使う（めたん → ずんだもん、ずんだもん → めたん）
- 数字・固有名詞はセリフの中で 1 回は省略せずに言う（字幕と図で同じ数字を出す）

## 3. 冒頭のつかみ

- 最初の 1 セリフで「何の話か」と「なぜ聞く価値があるか」を言う（例:「富士山には、意外と知られていない話が三つあるのだ」）
- あいさつ・自己紹介は 1 往復以内。茶番は 2 往復以内に収める

## 4. 点検（台本を書いたら必ず）

- [ ] 全セリフの一人称が、話者の設定と一致する（ほかのキャラクターの一人称が混ざっていない）
- [ ] 語尾が設定されたキャラクターは、その語尾がセリフの半分以上にある。語尾が無いキャラクターに他人の語尾（「のだ」など）が付いていない
- [ ] 相手の呼び方が設定と一致する。視聴者を乱暴に呼んでいない
- [ ] 設定に無い口癖・方言・乱暴な言葉が無い
- [ ] 性格の特徴の出し方が 1〜2 回で、話の流れを止めていない
- [ ] 同じ相づちが 3 回以上続いていない

違反は、そのセリフだけを書き直す（意味は変えず、一人称・語尾・呼び方を直す）。直したセリフは利用者に見せて承認を受ける。

## 5. アプリが自動で確かめること（書き手が頼りすぎないこと）

- 台本を作った直後に、口調の設定（「一人称は「…」」「相手は「…」と呼ぶ」「語尾は「…」」）から規則を読み、
  一人称・相手の呼び方の取り違えは決まった言い方に置き換える（かぎかっこの中の引用は変えない）
- 語尾が半分以上抜けた発話は、その発話だけ書き直しを頼み、規則に合う案だけを採る。合わなければ「確認」で警告として出す
- 規則で確かめられるのは一人称・呼び方・語尾だけ。性格（反応の仕方・役割）は書き手が守る
- 口調の設定を自由文で書くときも、上の 3 つは「一人称は「わたくし」」の形で書くと確かめの対象になる
